ADA Statement

SFC Estate Coaching recognizes the importance of providing a website that is accessible to all user groups. Please contact us if you have any questions or feedback regarding the accessibility of this site, or if you experience any difficulty using it. We have applied reasonable and affordable ADA-friendly tools to the best of our ability to help with navigating our site.

 Accessibility Features

  • All images have descriptive text alternates (ALT tag attributes).
  • All headings use appropriate H1, H2, H3, etc.
  • All pages use descriptive meta page titles and meta descriptions.
  • All text uses relative font sizes so text can be enlarged or reduced using the text size options available in visual browsers.
  • Added appropriate ARIA attributes
  • The site can be navigated with the use of a keyboard with contrasting focus elements.
  • The site was tested for color vision deficiency.
  • Pages can be accessed multiple ways (ie. nav menu, buttons, images, text links, sitemap).
